# Notes (legacy)

Đây là 5 note CloudWatch/CloudTrail từ track học cũ. Chúng được giữ để bạn không mất
công sức, nhưng **không phải evidence của track 24 lab hiện tại**.

Evidence chuẩn của track mới nằm ở:

```text
labs/<id>/evidence/note.md
labs/<id>/evidence/verify-last.txt
labs/<id>/evidence/DONE
```

Tạo note mới:

```bash
./bin/lab note <id>
```
